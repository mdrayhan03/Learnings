Part 1
1. Ans: here using SNI(Server Name Indication) so it want hostname in the request if this information is missing it drops the handshake.

2. Ans: it will give MISS, because nginx will look for cache but first time no cache found so MISS. but this is private so nginx will not cache it so in the 2nd and onward request it will do same check for cache and give MISS

3. Ans: we have forget to implement keepalive, without this in every request nginx do new handshake with the app and after request finish it close and when server load is more that time this everytime handshake takes time and make the Too many open files errors.

4. Ans: for real time chat we need websocket and for websocket we need to use two extra line
```
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "Upgrade";
```
